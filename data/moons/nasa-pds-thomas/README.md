# Phobos and Deimos — source data

Source: NASA Planetary Data System Small Bodies Node, *Small Body Optical Shape Models Bundle V1.0* (Peter Thomas et al., 2021), DOI: https://doi.org/10.26033/g5e0-kh52

Dataset landing page: https://sbn.psi.edu/pds/resource/oshape.html

This folder contains only archive files whose names identify Phobos or Deimos, plus their PDS labels/metadata where provided. The upstream archive also contains several unrelated small bodies, which are not included here.

These are source products, not yet converted into Three.js-ready meshes or optimised web textures. Preserve the PDS labels when interpreting table columns, coordinate conventions, and units.
